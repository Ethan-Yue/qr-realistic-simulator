| 载体        | 常见成码方式 | 典型视觉特征                           |
| ----------- | ------------ | -------------------------------------- |
| 普通纸张    | 激光打印     | 边缘锐利、黑度均匀                     |
| 普通纸张    | 喷墨打印     | 墨点扩散、边缘略毛                     |
| 普通纸张    | 胶印         | 网点细密、整体均匀                     |
| 普通纸张    | 热敏打印     | 黑色略发灰，可能有条纹、褪色           |
| 不干胶标签  | 热敏         | 快递单常见，纸面偏哑光                 |
| 不干胶标签  | 热转印       | 墨层更稳定、更黑                       |
| 不干胶标签  | 数码喷墨     | 可能有彩色背景、墨滴纹理               |
| 瓦楞纸箱    | 柔版印刷     | 墨层不完全均匀，受纸纹影响             |
| 瓦楞纸箱    | 喷码         | 点阵感明显、边缘颗粒化                 |
| 瓦楞纸箱    | 贴标签       | QR在白色标签上，与纸箱材质分离         |
| 塑料包装    | 凹版印刷     | 图案较平滑、适合大批量包装             |
| 塑料包装    | 柔版印刷     | 油墨略有铺展                           |
| 塑料包装    | UV喷墨       | 表面有一定墨层感                       |
| 塑料包装    | 热转印       | 边缘清晰、色块较稳定                   |
| 纸盒包装    | 胶印         | 最常见，印刷精细                       |
| 纸盒包装    | 数码印刷     | 小批量、颜色和墨层更直接               |
| 金属        | 激光打标     | 不是黑墨，表面被烧蚀或氧化             |
| 金属        | 激光雕刻     | 有凹陷、深度、阴影                     |
| 金属        | 丝网印刷     | 有明显墨层，可能轻微凸起               |
| 金属        | UV打印       | 彩色或黑色墨层附着表面                 |
| 塑料外壳    | 激光打标     | 表面发白/发黑，无明显墨层              |
| 塑料外壳    | 移印         | 墨层较薄，适合曲面                     |
| 塑料外壳    | 丝印         | 边缘略厚、墨层明显                     |
| 塑料外壳    | 标签贴附     | 最常见的设备铭牌方式之一               |
| 玻璃        | 丝网印刷     | 油墨附着玻璃表面                       |
| 玻璃        | UV打印       | 可彩色、有墨层                         |
| 玻璃        | 激光蚀刻     | 磨砂感、半透明感                       |
| 玻璃        | 贴膜/贴纸    | QR本身不直接在玻璃上                   |
| 木材        | 激光雕刻     | 深浅不均、木纹穿过QR                   |
| 木材        | 激光烧灼     | 棕黑色烧灼边缘                         |
| 木材        | UV打印       | 黑色墨层覆盖木纹                       |
| 木材        | 丝网印刷     | 墨层较粗、纹理明显                     |
| 纺织物      | 丝网印刷     | 受织物纹理影响明显                     |
| 纺织物      | 热转印       | 比较平整，但有膜感                     |
| 纺织物      | 数码直喷     | 墨水进入纤维，边缘略扩散               |
| 纺织物      | 织造/提花    | QR由纱线构成，不是“印刷”               |
| 纺织物      | 刺绣         | 模块由线迹构成，形状不完全规则         |
| 陶瓷        | 丝印         | 表面墨层                               |
| 陶瓷        | 热转印       | 常见于杯子                             |
| 陶瓷        | 釉下彩/烧制  | QR与釉面结合，纹理更自然               |
| 亚克力/PVC  | UV打印       | 非常常见，颜色饱和                     |
| 亚克力/PVC  | 丝印         | 墨层均匀                               |
| 亚克力/PVC  | 激光雕刻     | 亚克力会出现磨砂/发白效果              |
| 广告牌/海报 | 喷绘         | 墨点、网点、远距离观看设计             |
| 广告牌/海报 | 写真         | 分辨率高，表面更细腻                   |
| 广告牌/海报 | UV卷材打印   | 表面墨层和颗粒感明显                   |
| 票卡        | 热敏         | 常见车票、票据                         |
| 票卡        | 热转印       | 塑料卡、证卡                           |
| 票卡        | 数码印刷     | 会员卡、门票等                         |
| 电子屏幕    | LCD/OLED显示 | 不属于打印，存在像素、摩尔纹、屏幕反光 |
