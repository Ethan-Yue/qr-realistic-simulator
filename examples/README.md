# Small synthetic examples

`sourced_material_mild/` and `sourced_material_challenging/` each contain five generated image pairs, masks, metadata and a run manifest. They use the five CC0 material images in `qr/assets/backgrounds_real/`. `engineering_50/` contains four selected image pairs from a larger engineering run; the full 100-sample run is not redistributed here.

The two run manifests preserve the original output-directory argument used during generation; their sample folders were relocated into `examples/` for this release.

These QR images are simulations, not photographs of physical marked codes. Author-produced example images are shared under CC BY 4.0. Source material images remain CC0; see their provenance JSON. The small examples demonstrate the file format and code path but do not establish realism or population read rates.
